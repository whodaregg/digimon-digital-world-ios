# 当前范围

当前源码v0.7，默认仍为Digital Monster COLOR Ver.1，并可新增独立COLOR Ver.2。两者有各自角色名单、进化条件、作息、力量和8区顺序Quest。旧版COLOR LAB档案继续按旧实验规则读取、备份和恢复。

角色包扩展至35份原始归档PNG：Ver.1/Ver.2各17种养成角色及共用Alter-S。跨版本电光暴龙兽与偃月加鲁鲁兽通信后，无论胜败，各自伙伴可联展为Alter-S，保留原身份与本机备份。背景、外壳、食物图标和技能特效为重绘；缺少动作仍声明姿势回退，尚非原机逐帧时序复刻。

LCD、现代页面、错误、日志及设置接入四语显示模板和实际像素字体。系统原始错误保留其描述，长篇译文仍需母语审校。喂食不再把缩小的主页叠在菜单上，改为独立同坐标场景显示食物、进食或拒绝姿势，并在演出期间阻止重复喂食。

云盘合集可选择iCloud Drive或其它文件提供商文件夹，自动或手动另存全部设备；另一台手机选择同一文件夹后读取版本、验证并恢复为新设备。不会自动覆盖另一端进度，也不自动合并冲突奖励。详见[CLOUD_BACKUP.md](CLOUD_BACKUP.md)。

手机附近通信采用协议2，双方须更新至v0.7；包括会话校验、双方准备、实际战果保存、演出及防重放。Game Center能力、团队及Bundle ID现有统一配置脚本，但项目所有者的Apple团队、已注册Bundle ID与签名仍需配置，实际两台iPhone联调未完成。不能直接连接实体暴龙机。

仍未完成：其它世代的完整可玩规则和原版素材、其它Jogress组合、Tag/Colosseum、DMX XAI、真实Pendulum训练/战斗规则、实体机物理通信，以及全设备性能/无障碍和长期养成验收。其它机型目录继续标记待核验，不以换壳或虚构参数冒充完整机型。Sandbox摇晃输入仅为输入辅助。

[28项清单](FEATURE_STATUS.md)和[验证记录](VALIDATION.md)区分实际代码、通过检查和外部依赖。v0.6.0已发布旧IPA不包含本轮v0.7修改；本轮按约定先开发验证，待用户再次明确打包后才生成新IPA。
