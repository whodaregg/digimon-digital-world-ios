# 当前范围

v0.3以用户选定的 Digital Monster COLOR Ver.1 为默认机型。

已接入：四心养成、食物、A/B训练、分支进化、原版角色像素、8区Quest、作息与睡眠打扰、Cold/一只备份交换、治疗、死亡与重生、图鉴、三种显示模式、存档迁移与恢复。原味界面不再提供方向地图、HP伤害制或经验升级。

未完成：通信对战、跨版本联展、其他机型完整规则、所有角色/动作与原版背景素材、在线联机、iCloud、HealthKit、Apple Watch、Widget、正式发行签名和完整性能/无障碍验收。

17种Ver.1养成角色可按规则分支成长；第18个角色Alter-S现为最终区NPC。它的跨版本联展条件未实现，不会直接赠送。

官方说明书操作已核对，隐藏数值采用注明出处的社区资料。概率区间等资料分歧公开记录，尚无实体机并行一致性测试，见 [规则出处](RULE_SOURCES.md)。真实设备安装和长期养成仍待验证。

旧实验档继续使用原规则引擎，设置可先另存旧档再开始Ver.1；旧地图数据保留用于解码兼容，界面入口已替换。
