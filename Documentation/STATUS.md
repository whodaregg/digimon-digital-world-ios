# 当前范围

v0.9 已接入用户上传的844份图集，通过独立的「数码兽图集养成」档案使用通用养成、训练和战斗。该入口可从「机型与规则」进入，详细范围见[上传图集养成](ARCHIVE_CARE.md)。角色阶段与进化路线仍待补充。最新已发布IPA为v0.8.0，新增图集需后续打包。

当前源码v0.9，默认仍为Digital Monster COLOR Ver.1，并可新增独立COLOR Ver.2。两者有各自角色名单、进化条件、作息、力量和8区顺序Quest。旧版COLOR LAB档案继续按旧实验规则读取、备份和恢复。

角色包扩展至35份原始归档PNG：Ver.1/Ver.2各17种养成角色及共用Alter-S。跨版本电光暴龙兽与偃月加鲁鲁兽通信后，无论胜败，各自伙伴可联展为Alter-S，保留原身份与本机备份。背景、外壳、食物图标和技能特效为重绘；缺少动作仍声明姿势回退，尚非原机逐帧时序复刻。

LCD、现代页面、错误、日志及设置接入四语显示模板和实际像素字体。系统原始错误保留其描述，长篇译文仍需母语审校。喂食不再把缩小的主页叠在菜单上，改为独立同坐标场景显示食物、进食或拒绝姿势，并在演出期间阻止重复喂食。

云盘合集可选择iCloud Drive或其它文件提供商文件夹，自动或手动另存全部设备；另一台手机选择同一文件夹后读取版本、验证并恢复为新设备。不会自动覆盖另一端进度，也不自动合并冲突奖励。详见[CLOUD_BACKUP.md](CLOUD_BACKUP.md)。

手机附近通信和在线房间采用协议2，双方须使用v0.7或以上版本。按侧装需求，在线使用普通WebSocket房间，不要求Apple开发账号；Server目录提供已通过实际网络协议测试的中继与部署文件。公网需部署WSS服务器并填写地址，真实两台iPhone端到端仍待验收。Game Center仅保留为默认关闭的备用适配，不是使用侧装版的前提。不能直接连接实体暴龙机。

v0.8 支持导入用户有权使用的设备音效、动漫音效、音乐、语音和限定版资源。资源按机型、动漫世代及事件匹配，缺失时静音。尚无玩法对应的事件预留独立 ID，真机静音、蓝牙、来电和传感器待实测。[音频与运动说明](ORIGINAL_AUDIO.md)

仍未完成：其它世代的完整可玩规则和原版素材、其它Jogress组合、Tag/Colosseum、DMX XAI、真实Pendulum训练/战斗规则、实体机物理通信，以及全设备性能/无障碍和长期养成验收。其它机型目录继续标记待核验，不以换壳或虚构参数冒充完整机型。增强及Sandbox模式的手机运动训练支持加速度摇晃、重力倾斜、真实计步与虚拟A/B。
