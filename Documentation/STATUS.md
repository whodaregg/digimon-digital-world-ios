# 当前范围

当前源码v0.6，默认可创建的正式机型为Digital Monster COLOR Ver.1。旧版COLOR LAB档案保留原实验规则，仍可备份、切换和恢复；不将旧实验参数当成实体机规则。

已接入LCD内部养成菜单、右侧A/B/C、实际像素字体、经典/增强/Sandbox模式、独立设备档案与虚拟测试时钟。Ver.1包含四心、肉/蛋白质、A/B五次训练、17种养成角色、8区顺序Quest、逐场动画、作息、Cold/单备份、医疗、死亡重生、生命周期与图鉴记录。正式模式不加入该型号没有的HP、等级或EXP。

角色使用18份原始归档PNG：17种养成角色及Alter-S最终区NPC。背景、图标、技能弹及事件标记为重绘；部分动作使用已存在的姿势回退，尚非实体机逐帧时序复刻。

手机连接已实现附近发现/邀请/接受、双方确认、同版本战果计算与保存、通信演出及防重放；真实iPhone双机尚待验收。Game Center适配代码已加入，但构建默认关闭在线匹配，仍需Apple开发团队、Bundle ID能力及真实账号验证。它不能直接连接实体暴龙机。

未完成：其它世代的完整可玩规则和素材、跨版本Jogress、Tag/Colosseum、DMX XAI、真实Pendulum训练/战斗规则、全部现代页面四语翻译、实体机物理通信、iCloud同步及全设备性能/无障碍验收。Sandbox摇晃输入不是已核验的Pendulum机型支持。目录条目不等于已实现机型。

逐条对应用户28项要求的落实情况和依赖见[需求状态清单](FEATURE_STATUS.md)。实际通过与失败检查见[验证记录](VALIDATION.md)，不能将编译成功当成真实iPhone安装或双机验收。

收到用户打包指示后，已发布[v0.6.0未签名IPA](https://github.com/whodaregg/digimon-digital-world-ios/releases/tag/v0.6.0)，包含上述修改。真机SDK编译、平台/架构、包结构、18份原图、三份字体及下载后的SHA-256均已核验；实际iPhone签名安装仍待验收。v0.4旧包继续保留，不包含本轮改动。
