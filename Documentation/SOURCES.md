# 内容来源

v0.3新增独立Ver.1配置，规则依据与资料分歧见 [规则出处](RULE_SOURCES.md)，角色PNG来源及哈希见 [素材出处](SPRITE_CREDITS.md)。

`database.json`的通用Species模型仍保留旧实验档所需的HP/攻防、旧进化与生命周期字段；新游戏Ver.1只使用`dmc-ver1.json`对应规则，不读取这些旧平衡值。`balanceProvenance=original-balance`标记的是这些遗留字段，不能当作COLOR实体机数值。

角色英文、日文和中文名用于显示；官方资料核验字段通过`verifiedFields`单独记录，未核验字段不应宣称已官方确认。中文译名仍可能存在地区差异。

此前8种图集已扩展为Ver.1共18份。原始PNG未改字节，动作组合与速度由本工程配置；背景为重绘主题，不是原机背景资源。

其他机型仅为未开放的开发目录；联机协议、跨版本奖励、联展和正式发行授权未完成。
