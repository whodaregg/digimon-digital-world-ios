# 内置开发测试

v0.4提供隐藏的本机测试面板。主界面标题支持长按进入访问验证，访问码由项目所有者指定；正常菜单不展示入口。每次打开须重新解锁，关闭面板或应用进入后台会锁定。该入口在Debug及Release均保留，固定访问码是本机隐藏开关，不是账号身份认证或远程访问控制。

## 可用操作

- 指定当前内容包中的任意角色，包括18种Ver.1角色中的关卡NPC。直接指定会重置当前形态的养成值、结束未完成训练，保留该伙伴身份、历史和另一只备份伙伴。普通进化和通信联展条件不变。
- 发放现有道具，也可输入自定义道具ID和数量。库存上限999999；自定义ID不会自动产生未实现的道具效果。原味玩法仍只有肉与蛋白质的喂食效果。
- 编辑年龄、阶段时间、体重、DP上限/当前DP、四心、训练、照顾失误、满腹、睡眠打扰、战绩、伤势及各类计时；旧版规则另可编辑HP、攻击、防御、速度和暴击。
- Ver.1战斗基础力量和DP上限覆盖会实际参与Quest、蛋白质恢复和睡眠恢复。力量仍叠加原味四心/强力蛋加成；正常进化会恢复新形态的默认战斗参数。
- 成长、Cold、死亡、伤势、关灯、强力蛋加成和进化判定状态可用于测试。正常养成计时继续运行；数值页为独立草稿，保存写回全部草稿，过期形态的草稿会拒绝写入。

数值只在可保存、可计算的范围内接受整数；胜利不超过战斗、训练成功不超过尝试、DP不超过容量。错误输入整次拒绝，不会部分写入。修改只影响当前存档/伙伴，不重写角色资料库或原版PNG。

## 备份与识别

每次解锁后的首次有效修改前，先原子保存独立的`world.before-developer.*.json`快照；本次后续操作不轮换这份快照。备份可从测试面板导出或恢复，重新启动应用后仍可找到最近一份。

修改后的存档带测试时间标记，主界面页脚显示“开发测试档”，日志记录操作。恢复调试前快照会恢复其原有标记、角色及库存。

存档格式为v4，兼容v1/v2/v3迁移；旧版本应用会拒绝打开v4，避免丢失测试覆盖数据。访问解锁状态不写入存档。

## 验证

核心新增9项测试，覆盖全部角色指定、道具边界、事务拒绝、真实战斗覆盖、DP容量、旧版战斗、过期草稿、备份伙伴及v3迁移。另增加原生界面用例验证错误访问码、后台/关闭后上锁，以及角色→发道具→改力量→恢复备份的完整操作。实际结果记录在[实测记录](VALIDATION.md)。
