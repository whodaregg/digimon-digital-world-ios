# 云盘设备合集

设置页面可选择iCloud Drive或其它支持文件夹访问的云盘。系统文件选择器授予该文件夹访问权限；无需在工程内保存Apple账号、云盘密码或个人证书。

选择文件夹后，手动“立即备份全部设备”保存完整设备合集。开启自动快照时，应用使用期间或转入后台时每15分钟最多尝试一次；失败不会每秒反复上传，手动操作可立即重试。系统云盘负责上传、下载和账号认证，应用不能承诺后台持续运行或系统同步时限。

每份`.worldarchive`是独立版本，包含设备索引、正式及Sandbox存档和来源绑定。文件名包含时间和随机编号，另一台手机不会覆盖同名进度。另一台手机选择同一云盘文件夹后刷新，点击版本、验证并确认恢复即可继续养成。iCloud占位文件在读取前请求下载；没有本地文件时仍需要网络和系统云盘可用。

恢复先验证全部记录，再写入新的设备目录，最后发布索引。失败清理本次新建目录，不覆盖既有设备。原设备、云端快照和冲突版本均保留；用户选择继续哪一版，应用不自动合并两个同时养成的同一伙伴，也不合并战绩奖励。合集编码上限128MiB，源存档预检上限64MiB；超过容量可分别导出单台设备。

这是通过系统文件提供商进行的版本化备份与恢复，不是CloudKit实时合并。真实双手机云端下载、账号切换及文件提供商离线行为仍需验收。
