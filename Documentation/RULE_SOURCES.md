# Digital Monster COLOR Ver.1 规则出处

本实现以用户选定的 COLOR Ver.1 为基准。操作经官方说明书核对，隐藏阈值和数值使用公开社区实测；不宣称已经过实体机逐项一致性验收。

规则以 `Scripts/dmc_content.py` 生成 `Resources/dmc-ver1.json`，独立于旧版 `Species.stats/evolutions` 中的实验数值。新游戏仅走 `dmc-ver1` 引擎；旧档不自动套用这些规则。

## 已明确的流程

- 8秒孵化；幼年期Ⅰ10分钟、幼年期Ⅱ12小时、成长期24小时、成熟期36小时、完全体48小时。睡眠计入成长，Cold和备份不计。
- 饱食和力量0～4心；肉＋1饱食心/＋1g，蛋白质＋1力量心/＋2g，每4份＋1DP。满腹后再喂10份肉达到满腹记录（幼年期Ⅰ例外为4份）；并延后一轮心值下降。
- 训练5次A/B攻击，命中至少3次才加力量心。完整训练无论成败均记一次、减重1g，努力每4次加一心，上限四心；取消不计。
- 空腹/力量呼叫10分钟宽限，各自计失误；睡眠呼叫1小时。就寝时间依角色，08:00醒；开灯时选择食物/训练/战斗可打扰睡眠10分钟。
- Quest按AREA 1～7、F顺序解锁。每区固定3～5个敌人，先命中3次获胜，最多5回合；一旦开始连战至通关或败北，失败后重试从该区首战开始。每次整区消耗1DP/6g，每场分别记战绩。
- 进化按本阶段训练、照顾失误、满腹、睡眠打扰和战绩分支。重量不参与原味进化，不使用经验或进化芯片。
- Cold暂停当前伙伴；一只备份可交换，交换后饱食/力量归零。养成史和图鉴持久保存。
- 原味养成不套用旧版固定14天寿命和HP伤害制。

## 尚待实体机复核的部分

1. 胜率60～69%的进化概率：Humulos记50%，NHOKO记25%。当前选择前者；40～59%为25%，80%以上必定。该差异公开记录，不能描述为官方已确认数值。
2. 完全体所需15战采用NHOKO“成长期＋成熟期合计”；究极体需要在完全体阶段另打15战。不同资料对重置范围的描述并不完全一致。
3. 心值下降周期使用社区的近似分钟数；未测得硬件的秒级周期。训练动作时序和背景是本工程表现；v0.5战斗分镜按说明书的交替出招、回避、骷髅命中标记与胜败顺序实现，重绘特效和播放速度仍非实体机逐帧时序复刻，见[战斗表现说明](BATTLE_PRESENTATION.md)。
4. 未完成一整条进化路线的实体机并行养成对照。原味模式表示选定规则配置，不表示全参数逐位一致。
5. 同应用手机通信已实现双方前三轮命中、第四轮决胜和战果结算，真实双机及实体机并行对照尚待验收；跨版本连接奖励、联展及实体机物理通信未实现，见[连接说明](CONNECTION.md)。Alter-S仅为最终区NPC；不会通过普通进化发放。连战受伤概率和连续受伤表现也需硬件对照。

屏幕背景是重新绘制的像素主题，角色PNG使用归档原始字节。角色来源见 [素材出处](SPRITE_CREDITS.md)。不使用其他同人游戏自定的进化阈值作为实体机依据。
