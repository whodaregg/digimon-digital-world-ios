# 真机验收清单

以下是尚需实际执行并记录设备、系统版本和结果的验收项目。清单本身不表示已经通过。

## 安装与基本体验

- 用自己的开发团队签名，安装到 iOS 17 的 iPhone，以及较新系统的 iPhone/iPad。
- 首次启动选择数码蛋，观察 5 分钟真实孵化；期间锁屏和强制退出，确认再次打开正常结算。
- 验证 LCD 单色、Retro Color 与 Advanced Pixel 的像素边缘、日夜背景与减少动态效果设置。
- 检查小屏设备、大字体、VoiceOver、iPad 横竖屏和分屏情况下的按钮可达性。
- 检查 A 选择、B 确认、C 返回，与触屏直接操作是否一致。

## 时间与生命周期

- 健康伙伴离线 1 小时、8 小时、24 小时后检查饱食、排泄、疾病和照顾失误。
- 对同一初始存档分别一次结算与分次重开，比较最终数据。
- 21:00 后关灯，次日 07:00 查看恢复情况；检查旅行时区变化不重写养成作息。
- 冷冻后离线一天，解冻时确认年龄、饱食和健康没有补扣。
- 调整设备时间向后，确认阻止重复成长；恢复正确时间后确认继续成长。
- 连续培养至少一周，检查分支进化、特殊道具只消耗一次、衰老与死亡记录。
- 重生后检查图鉴和过去的进化顺序保留，旧档案不能重复创建额外存活伙伴。

## 操作与数据

- 逐种喂食，检查库存、体重和过量喂食惩罚；肉与蛋白质供应不受背包限制。
- 清洁废物、等待疾病、治疗并确认伤病消失；正常健康状态应拒绝无意义用药。
- 训练准确/失败各一次，取消一次，快速连点一次，确认计分与次数不重复。
- 离线 PVE 胜负各一次，检查体力、DP、伤势、恢复奖励、图鉴与战绩。
- 探索地图三个宝箱，绕路返回相同宝箱确认不可重复领取；完成任务领取进化芯片。

## 存档与恢复

- 操作后立即终止应用，重开确认操作已经持久化。
- 将导出的 JSON 保存至「文件」，从应用恢复入口选择它，查看待恢复伙伴与时间，取消一次、确认一次。
- 恢复前检查当前进度另存为 `world.before-restore.*.json`，原档案不因后续备份轮换而丢失。
- 在开发沙盒中损坏主文件，确认自动恢复有效备份并保留损坏副本。
- 两份文件都损坏时确认阻止静默重置，并能进入已验证备份恢复入口。
- 磁盘空间不足、文件访问被拒绝时确认显示可理解的错误。

## 系统与性能

- 拒绝通知授权，确认养成不受影响；授权后检查安静时段和基础提醒。
- 静音模式、按键音关闭、触觉关闭、播放其他音乐时分别验证反馈。
- 用 Instruments 测量启动、内存、前台能耗、长离线结算开销；至少持续运行 30 分钟。
- 验证 Release 包不接受 UI 测试初始化参数，不要求联网、健康或蓝牙权限。
- 发布前完成正式素材授权、角色资料核实、隐私和 App Store 内容审查。
