# 真机验收清单

以下是待执行的真实设备验收，不能把模拟器通过当作真机验证完成。

- 在真实iPhone/iPad签名安装，验证iOS17最低系统、iPad布局、大字体、VoiceOver、静音开关与触觉。
- 开始Ver.1新蛋，确认8秒孵化；关闭/重开与连续前台的成长一致。
- 验证四心、肉/蛋白质、满腹拒绝、蛋白质恢复DP与体重上下限。
- A/B训练成功和失败均计次数；取消不计；尝试跨后台、进化和死亡后的未完成训练。
- 与实体COLOR Ver.1并行验证分支、心值下降、失误宽限、受伤、死亡；特别复核文档中的概率分歧。
- Quest解锁1～7/F、固定敌人顺序、失败重置、整区DP/体重消耗、战绩和背景奖励去重。
- 验证整区结果在演出前已保存，杀掉应用不能重抽同一次挑战。
- 角色就寝/08:00起床、关灯、睡眠打扰10分钟、连续8小时恢复DP、Cold无追补成长。
- 备份只保存一只、交换心值归零且成长记录保留；存档历史不能重复生成并行活体。
- 三种显示切换并杀掉/重开应用，确认保留选择，原版PNG尺寸与像素不糊。
- 导出/文件导入、主档损坏恢复、未来版本拒绝、旧档迁移和另存旧档后开始Ver.1。
- 同型号建立两个正式设备，分别进入Sandbox、改值和推进时间；返回各自来源，确认经典/增强模式、角色和正式图鉴保持隔离；旧版调试快照恢复不能变为正式档案。
- 两台iPhone允许本地网络后，执行附近搜索、邀请/拒绝、双方准备、胜败演出、再次对战、断线重连与重复消息，核对DP、战绩和通信收据只结算一次。Game Center需先完成团队和能力配置。
- 验证本地通知权限、实际送达与安静时段；长时间离线、电量、Instruments性能/内存及一周养成。

开发测试真机补验：长按入口、错误访问码、后台/关闭后锁定、Release实际安装后的入口、修改与重启持久化、独立快照导出与恢复。验证高力量及DP覆盖不会影响普通新档，正常进化后恢复默认战斗参数。
