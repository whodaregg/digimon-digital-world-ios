# 28项需求落实与依赖清单

对应[完整需求](FEATURE_REQUEST.md)。当前源码版本v0.9，默认机型仍为用户选定的Digital Monster COLOR Ver.1。下表区分可运行代码、未实现功能和待真机验收；不把机型目录当成已支持的机型。

| 需求 | 当前实现 | 剩余部分或依赖 |
| --- | --- | --- |
| 1.真实功能 | LCD操作调用核心并保存后发布状态；动画只回放已保存结果 | 无静态按钮冒充已实现功能 |
| 2.UI与视觉 | 彩色LCD、右侧A/B/C、8个像素图标、真实像素字体；收藏/设置独立 | 外壳、背景和事件图标为重绘；非逐像素外壳复刻，多尺寸/无障碍仍需设备验收 |
| 3.按键 | A选择/B确认/C返回、防抖、多指组合、按压反馈；A+C切音效、C长按2秒设置、死亡时A+B重生、时钟A+C设置时间 | 长按/组合已接入实际状态；真实多指与触觉待iPhone验收 |
| 4.主页 | 大角色走动/转身/停留/跳跃、进食/拒绝/睡眠/伤势/进化/死亡、排泄物与呼叫 | 无对应原图的眨眼等动作使用声明的已有姿势回退 |
| 5.Status | LCD六个原机分页；增强模式附加战绩/编号，现代详情显示养成数据；经典模式隐藏条件/失误 | COLOR Ver.1没有HP、等级和EXP，不为它编造这类数值 |
| 6.Feed | Ver.1/Ver.2肉/蛋白质、四心/体重/满腹/过量记录；独立LCD喂食场景、原图进食/拒绝、连续输入锁定 | 其他机型食物需独立规则包 |
| 7.Training | Ver.1五次A/B训练，影响力量/努力/战绩；增强和Sandbox接入加速度摇晃、重力倾斜、系统计步与虚拟A/B | 摇晃输入不是已核验的Pendulum规则；墙壁、蓄力等机型训练尚未完成 |
| 8.Battle | 固定Quest/CPU/BOSS；手机通信确定战果、校验双方、一次消耗与战绩/伤势/进化计数；完整演出 | Tag、Colosseum未实现；侧装在线房间不依赖Game Center；服务器部署及双机链路待验收 |
| 9.Clean | 按成长时间产生排泄物、累积影响伤势；真实清理、冲水演出和音效 | 不同型号的疾病参数待对应数据包 |
| 10.Sleep | 独立角色就寝时间、08:00醒、关灯、睡眠呼叫/打扰、8小时恢复DP、ZZZ | 其他机型作息未接入 |
| 11.Medical | 原味伤势、按角色多次治疗、恶化死亡、像素治疗反馈 | 非Ver.1疾病机制需各机型数据 |
| 12.Call | 原机宽限/失误判定、图标闪烁、电子音、按同一引擎预测多个设备的本地通知 | 系统送达受iOS控制，真实通知送达待验收 |
| 13.Real-Time | 同一时间引擎按顺序结算离线，保留高水位，倒退时阻止重复奖励；设备时钟设置只改变作息与显示，不快进成长 | 纯离线时钟不是联网可信时间认证 |
| 14.Digivolution | Ver.1/Ver.2各17种养成角色、独立分支JSON、截止判定、优先级及进化演出 | 其它世代、X抗体与特殊分支缺已核验数据；Alter-S可由指定跨版本通信联展获得 |
| 15.Jogress | Ver.1电光暴龙兽与Ver.2偃月加鲁鲁兽通信后，无论胜败各自进化为Alter-S；保留伙伴身份和本机备份，收据防重放 | 其它版本组合仍需独立规则与角色包；真实双机联展待验收 |
| 16.Quest | AREA 1～7/F，固定敌人、Boss、顺序解锁、背景奖励、失败重试；每一战演出 | Ver.1不奖励EXP/道具；DMX的XAI、其它机型随机事件/隐藏敌人未接入 |
| 17.死亡重生 | 墓碑反馈、保存最终形态/年龄/战绩/历史；重生继承图鉴，超过32只转入生命周期档案 | 16MiB存档容量保护会在超限写入前拒绝；可导出备份 |
| 18.Sprite | 统一PixelActor/帧时钟、原始图集、最近邻、缺帧回退声明；三种显示与减弱动态效果 | 部分角色缺少独立攻击/眨眼等原图，不能宣称全动作原机逐帧复刻 |
| 19.Device Profile | COLOR Ver.1/Ver.2可实际养成；独立名单、分支、作息、力量与Quest；保留旧实验档 | 目录中的其他世代不能游玩，缺说明书逐项参数/角色/素材包；不会仅换壳宣称支持 |

| 21.Digidex | 四语角色名、搜索、属性/阶段/设备/收藏筛选、剪影、动画预览、首次获得/次数/完成率、分支 | 旧档未记录的首次日期显示未知；原有35条角色外新增844条上传图集记录，合计879条；新增名称与阶段待核对 |

| 23.Connection | Multipeer发现/邀请/接受/可靠消息、单对手与会话回调校验；协议2支持Ver.1/Ver.2及联展；独立在线房间与两人中继，不需Apple开发账号 | 公网房间需部署WSS服务器；真机双机/断线验收未完成；实体机物理通信未实现 |
| 24.Settings | 音效/音量/触觉、LCD亮度/对比度/配色/背景、外壳、LCD菜单/角色名四语、通知、备份/导入/重置二次确认，授权音频资源库及每机型三种音频模式 | 872条模板与术语覆盖现代页面、错误、日志及无障碍提示；系统错误保留原文，长篇译文需母语审校 |

## 无法仅靠当前素材包完成的部分

- 其余世代的逐型号操作、数值、进化、训练、战斗和完整原版素材。目录的“待核验”不是虚构的可玩支持。
- 其它世代的Tag/Colosseum、DMX XAI和真正Pendulum规则；实体机通信硬件及协议，及双设备并行验收。
- 侧装版不要求Game Center或Apple开发团队。公网在线需部署随附中继并提供WSS地址。
- iOS17最低系统、不同iPhone/iPad尺寸、触觉、运动传感器、本地网络与通知送达需要真实设备验收。

原版素材、字体和规则依据分别见[像素出处](SPRITE_CREDITS.md)、[字体出处](FONT_CREDITS.md)、[规则来源](RULE_SOURCES.md)。
