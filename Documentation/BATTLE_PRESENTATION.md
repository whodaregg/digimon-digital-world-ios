# Ver.1 Quest战斗与主页动作

v0.5将文字回放替换为实际SpriteKit像素演出。依据[Bandai Ver.1/Ver.2说明书](https://toy.bandai.co.jp/manuals/files/2645513.pdf)第13～15页：敌人登场、BATTLE、伙伴和敌人交替出招、回避或骷髅命中标记、胜败动作、自动接续下一位敌人；区域末位先显示BOSS登场。Quest与通信对战演出不同，本次不加入通信对战。

- 每次攻击实际切换原版图集姿势并显示移动的像素弹；回避有位移动作，命中切换闪烁的骷髅标记画面，胜利有庆祝动作，败北有沮丧动作。
- 每场都播放，不再依靠文字逐行出现；胜利自动接下一战，失败结束本区。可跳过当前演出。
- 伙伴形态取进入Quest时的角色，回放途中不会随主页成长变形。战果先保存；演出、跳过、关闭和重复展示都不调用随机数或再次扣DP。
- 保存明确的命中顺序，旧战绩缺少新字段时兼容读取原有日志。存档仍为v4，不改养成、命中率、敌人顺序或消耗。
- 主页图集显示增至192×192，伙伴会来回走动、转向、停留和开心；喂食、睡眠、伤势、死亡和Cold优先中断闲逛。动作结束恢复日常活动。
- 三种显示模式沿用原设置。系统“减弱动态效果”下关闭位移、闪烁与循环帧，保留静态出招、回避和胜败分镜。

角色PNG保持原始归档字节，出处见[素材说明](SPRITE_CREDITS.md)。归档图集没有技能弹、命中标记和场景，因此这些画面按说明书示意重新绘制；不是官方动画资源。动作顺序参考原机，播放秒数和全部像素尚未经过实体机逐帧对照，不能宣称固件或逐帧完全一致。

验证结果见[实测记录](VALIDATION.md)。仅Debug界面测试启动参数启用实际节点位置、朝向、姿势、帧编号与技能弹节点的诊断读数，Release不包含这些读数。
